PDF 工具组（BAT 便携版）
========================

适用系统
--------
Windows 10 64 位（x64）。本机离线、免安装便携使用，无需安装 Python 或 qpdf。
完整解压整个工具包，不要只复制 BAT。

两个独立工具
------------
1. PDF权限处理工具.bat
   为“可以直接打开，但受到普通编辑或注释权限限制”的 PDF 生成新副本，供你在福昕阅读器中重新尝试“打字机”等注释功能。

2. PDF去水印工具.bat
   仅清除具有明确结构标记的水印，具体范围见“去水印边界”。

仅限处理你有权修改的文件。不猜测、不破解未知的打开密码。

使用方法
--------
方法一：双击需要的 BAT，在弹出的文件选择框中一次选择一个或多个 PDF。
方法二：在资源管理器中多选 PDF，拖到对应 BAT 上。

开始前会提示：原文件不会被覆盖；生成副本可能使数字签名失效。确认后才会处理。
两个工具独立使用，根据需要选择入口。

输出规则
--------
输出保存在原 PDF 所在目录。

权限工具：原文件名_可注释.pdf
同名已存在时：原文件名_可注释_2.pdf、原文件名_可注释_3.pdf……

去水印工具：原文件名_去水印.pdf
同名已存在时：原文件名_去水印_2.pdf、原文件名_去水印_3.pdf……

不会覆盖原件或已有输出，不修改或删除原 PDF。输出校验通过后才保存为最终文件。
去水印未识别时跳过，且不生成副本。

去水印边界
----------
只清除内容流中明确标记为 /Artifact 且 /Subtype /Watermark 的结构化水印。
不根据颜色、角度、透明度或重复文字猜测。
不处理扫描图片/像素水印、普通正文、页眉页脚。

肉眼能看到水印，不代表文件含有可处理的结构标记。未识别时跳过且不生成副本。
检测到标记不等于一定处理，安全优先：即使检测到 /Artifact 且 /Subtype /Watermark，如果水印位于后续正文之前，且包含可能跨边界影响文本位置、当前路径或裁剪等状态的内容，工具无法证明删除安全时会跳过，不生成副本。
成功表示移除了识别到的结构化水印块，页面上其他形式的水印可能仍存在，请检查输出内容。

处理结果
--------
成功：已生成副本。权限工具输出可用福昕打开，再试“打字机”；去水印输出请检查页面内容。
警告成功：已生成副本，但检查发现可恢复的文件结构问题，请检查新文件是否完整。
跳过：输入不存在、不是 PDF、未识别到支持的结构化水印，或无法确认删除不会影响其他内容；不生成副本，具体原因请看窗口提示。
失败：未生成最终副本，请查看窗口提示。单个文件失败不影响批次中的其他文件。

常见原因与处理
--------------
1. 文件需要打开密码
   该 PDF 不能直接打开。本工具不破解未知的打开密码，遇到此类文件不继续处理。

2. 文件损坏、格式无效或无法解析
   文件可能不是有效 PDF，或内部结构已损坏。请确认文件可正常打开。

3. 原文件目录没有写入权限
   请把 PDF 复制到桌面、文档等可写目录后重试。

4. 提示依赖缺失或版本不符
   工具目录可能不完整。请重新完整解压工具包，不要只复制 BAT。

5. 已生成权限副本，但福昕仍不能使用打字机
   原因可能不是普通 PDF 权限限制，也可能与数字签名、认证限制、文件结构或福昕当前工具状态有关。

6. 看得见水印，却提示跳过
   可能是扫描图片/像素水印，或没有明确结构标记的文字、图形。此类内容不在处理范围内。

7. 去水印输出校验失败
   该文件未生成最终副本。保留原件，查看窗口中的具体原因；其他文件继续处理。

数字签名说明
------------
重新生成 PDF 可能使原有数字签名或认证签名失效。本工具不保证保留签名有效性。

隐私与安全
----------
- 所有文件仅在本机处理，不上传 PDF，不调用在线 PDF 服务。
- 不采集 PDF 内容，不保存文件清单或密码。
- 不修改、删除或覆盖原件。
- 仅限处理你有权修改的文件。
