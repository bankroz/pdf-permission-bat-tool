PDF 权限处理工具（BAT 便携版）
================================

适用系统
--------
Windows 10 64 位（x64）。无需安装 Python 或 qpdf。

用途
----
为“可以直接打开，但受到普通编辑或注释权限限制”的 PDF 生成一个新副本，供你在福昕阅读器中重新尝试“打字机”等注释功能。

本工具只处理你有权修改的文件。它不猜测、不破解未知的打开密码。

使用方法
--------
方法一：双击“PDF权限处理工具.bat”，在弹出的文件选择框中选择一个或多个 PDF。

方法二：在资源管理器中选择一个或多个 PDF，拖到“PDF权限处理工具.bat”上。

开始前会显示提示：原文件不会被覆盖；生成副本可能使数字签名失效。确认后才会处理。

输出规则
--------
输出保存在原 PDF 所在目录。

首次输出：原文件名_可注释.pdf
如果同名文件已存在：原文件名_可注释_2.pdf、原文件名_可注释_3.pdf……

工具先写入临时文件，只有 qpdf 成功且输出非空时才改为最终文件名。原 PDF 不会被修改或删除。

处理结果
--------
成功：已生成副本。请用福昕打开新文件，再试一次“打字机”。

警告成功：qpdf 已生成副本，但发现可恢复的文件结构问题。请自行检查新文件是否完整。

失败：单个文件失败不会中断同一批次中的其他文件。

常见失败原因
------------
1. “文件需要已知的打开密码”
   该 PDF 不能直接打开。没有已知密码时，本工具不会破解或处理。

2. “文件损坏、格式无效或 qpdf 无法解析”
   文件可能不是有效 PDF，或内部结构已损坏。

3. “原文件目录没有写入权限”
   请把 PDF 复制到桌面、文档等可写目录后重试。

4. “未找到随程序附带的 qpdf.exe”
   工具目录不完整。请重新解压整个文件夹，不要只复制 BAT。

5. 已生成副本，但福昕仍不能使用打字机
   原因可能不是普通 PDF 权限限制，也可能与数字签名、认证限制、文件结构或福昕当前工具状态有关。

数字签名说明
------------
重新生成 PDF 可能使原有数字签名或认证签名失效。本工具不保证保留签名有效性，也不主动使用 qpdf 的签名限制移除选项。

隐私与安全
----------
- 所有文件仅在本机处理。
- 不联网上传 PDF，不调用在线 PDF 服务。
- 不收集 PDF 内容，不保存文件清单或密码。
- 不覆盖原件。

随附软件
--------
qpdf 12.4.2（Windows msvc64 官方发布包中的运行时文件）
官方项目：https://github.com/qpdf/qpdf
许可证及版权文件：licenses 目录

版本边界
--------
这是先行 BAT 版，用于验证批量处理闭环。后续图形界面版本可复用相同的命名、错误处理和测试规则。
