# 结构化 PDF 水印清除工具设计

## 背景

现有项目提供 Windows 10 x64 便携式 PDF 权限处理工具。新增能力以独立 BAT 入口交付，用于批量清除用户有权修改的 PDF 中、被明确标记为结构化水印的内容。

首个验收样本为：

`E-2978_AQI_compact_Funktionstest_report_2_可注释.pdf`

样本共 4 页，页面内容流中的斜向红色水印满足以下结构特征：

- 标记内容标签为 `/Artifact`；
- 属性字典包含 `/Subtype /Watermark`；
- 水印绘制位于对应 `BDC` 和匹配的 `EMC` 之间；
- PDF 还包含名为 `Watermark` 的可选内容组，但首版不依赖该弱特征进行删除。

## 目标

新增 `PDF去水印工具.bat`，让 Windows 10 x64 用户可以双击批量选择 PDF，或把多个 PDF 拖到 BAT 上。工具在本机离线识别并删除高置信度的结构化水印内容块，生成新副本，不覆盖原文件。

## 非目标

首版不处理：

- 扫描图片中已经烙入像素的水印；
- 普通正文、页眉或页脚形式的重复文字；
- 仅凭颜色、透明度、角度或重复次数推测出的疑似水印；
- 需要未知打开密码的 PDF；
- 通用 PDF 内容修复、OCR 或图像修复；
- 原地覆盖输入文件。

## 用户交互

1. 用户双击 `PDF去水印工具.bat`，通过系统文件选择框一次选择一个或多个 PDF；也可以在资源管理器中多选 PDF 后拖到 BAT 上。
2. 工具显示授权和风险提示：只处理用户有权修改的文件；原文件不会被覆盖；新副本可能使数字签名失效。
3. 工具逐个处理文件并显示成功、跳过或失败状态。单个文件异常不得中断整批任务。
4. 成功文件写入输入文件所在目录，默认命名为 `原文件名_去水印.pdf`。重名时依次使用 `_去水印_2.pdf`、`_去水印_3.pdf`。
5. 处理完成后汇总数量；只有全部未失败时返回成功退出码。交互模式下可选择打开唯一输出目录。

## 检测与删除规则

核心使用 PDF 内容流的已解析操作符，而不是对 PDF 二进制文件执行文本正则替换。

候选块必须同时满足：

- 起始操作符为 `BDC`；
- 第一个操作数是 PDF 名称 `/Artifact`；
- 第二个操作数是字典；
- 字典的 `/Subtype` 精确等于 PDF 名称 `/Watermark`；
- 在同一内容流中能找到正确嵌套层级上的匹配 `EMC`。

删除范围从候选 `BDC` 开始，到其匹配 `EMC` 结束，包括首尾操作符。除该范围外的操作符顺序和操作数不得主动改变。允许一个页面包含零个或多个候选块。

至少删除一个候选块才视为成功；完全没有高置信度候选块的文件必须返回“未发现支持的结构化水印”并跳过，不生成副本。遇到未闭合或层级异常的候选块时，整个文件失败，不输出半成品。

## 技术架构

### BAT 入口

`src/PDF去水印工具.bat` 仅负责定位自身目录并启动 Windows PowerShell 5.1。BAT 保持纯 ASCII、无 BOM，不使用 `chcp 65001` 和延迟扩展，以兼容中文及 shell 特殊字符路径。

### PowerShell 调度层

`src/tools/watermark_ui.ps1` 负责：

- 文件选择和拖放参数接收；
- 输入路径及扩展名检查；
- 唯一输出路径生成；
- 授权确认、逐文件调度和中文结果汇总；
- 在同目录创建随机临时输出，验证通过后再原子移动到最终文件名；
- 异常清理和退出码管理；
- 调用便携核心 EXE 和随包 qpdf，不解析或重写内容流。

### 水印核心

`src/watermark_core/watermark_core.py` 使用 BSD-3-Clause 许可证的 `pypdf`：

- 打开 PDF，并拒绝无法在无密码情况下读取的文件；
- 解析每一页的内容流操作符；
- 按上述严格规则定位和删除结构化水印块；
- 克隆文档，保留页面、注释、元数据和可读取的其他文档结构；
- 把结果写入调用方指定的临时路径；
- 以稳定退出码和 UTF-8 JSON 结果向 PowerShell 返回状态。

构建时使用 PyInstaller 和 Python 3.10 生成 Windows x64 独立 EXE。运行时不要求目标电脑安装 Python，不联网、不上传文件。

### qpdf 验证

现有随包 qpdf 继续作为独立验证器。PowerShell 在核心生成临时 PDF 后执行：

- `qpdf --check 临时文件`，只接受退出码 0 或表示警告的退出码 3；
- 比较处理前后页数；
- 确认输出文件存在且非空。

验证失败时删除临时文件，不生成最终副本。

## 输出与错误模型

核心状态分为：

- `success`：删除了至少一个高置信度水印块并写出临时文件；
- `unsupported`：PDF 可读取，但没有支持的结构化水印；
- `encrypted`：需要未知打开密码；
- `invalid`：不是可解析 PDF 或内容流结构异常；
- `failed`：写入、权限或其他未预期异常。

核心 JSON 至少包含 `status`、`message`、`pages` 和 `removed_blocks`。PowerShell 将其映射为面向用户的中文消息，不在正常界面暴露堆栈信息。

## 安全边界

- 不修改、删除或重命名原文件。
- 不破解或猜测未知密码。
- 不根据视觉相似度猜测水印。
- 不调用网络服务，不收集文件名或内容。
- 不把用户样本提交到 Git 或打入公开 Release。
- 新副本可能导致原有数字签名、认证签名或增量保存历史失效，必须在处理前提示。
- 失败时保留原件并清除本工具生成的临时文件。

## 测试策略

### 核心单元与集成测试

- 单个标准 `/Artifact + /Subtype /Watermark` 块被删除；
- 同页多个水印块全部删除；
- 多页文件逐页处理；
- 普通 `/Artifact`、普通标记内容和正文不被删除；
- 嵌套标记内容按层级正确匹配；
- 未闭合水印块失败且不生成输出；
- 无水印文件返回 `unsupported`；
- 加密、损坏和不存在文件返回稳定状态；
- 中文、空格、`&`、括号等路径字符可用。

### PowerShell 与便携包测试

- 批量隔离、同名递增、原件哈希不变；
- 核心 EXE 缺失或版本异常时给出明确错误；
- qpdf 验证失败时不发布临时结果；
- 从构建后的便携目录和 Release ZIP 实际启动 BAT；
- 依赖许可证和 SHA-256 清单进入交付包。

### 典型样本验收

对用户提供的 4 页样本执行真实处理：

- 删除的结构化水印块总数为 4；
- 输出页数仍为 4；
- qpdf 结构检查通过；
- 原文件 SHA-256 保持不变；
- 文本提取结果不再包含两条水印文字，但正文文本仍存在；
- 渲染抽查首页和末页，红色斜向水印不可见，正文和表格未出现明显缺失。

## 发布边界

本功能与现有权限处理功能放在同一便携目录，但入口和处理逻辑相互独立。README 和使用说明要明确两种工具的用途及限制。公开仓库中提交源代码、构建脚本、测试和第三方许可证；不提交构建产物、Python 虚拟环境、用户样本和分析临时文件。
